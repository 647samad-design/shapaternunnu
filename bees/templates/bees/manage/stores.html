Add a store

  1. Point the client's domain (e.g. shop.client.com) at this server.
  2. Run python manage.py store_create client --host shop.client.com --name "Client Shop" --owner-email owner@client.com (add --currency EUR, --database postgres://… or --demo if needed).
  3. Reload the web app. The owner signs in with the password shown, runs the setup wizard and adds their own payment and email keys.
  4. Scheduled jobs: use python manage.py for_each_store daily_tasks (and for_each_store run_promotions) instead of the single-store commands; after updates run for_each_store migrate.
